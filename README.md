# «Пойдём?» — генератор открыток-приглашений на события

Проект хакатона **«Креаторы и Кодеры»** (Universal University × Школа 21 / Сбер).
Кейс от медийно-сервисной платформы **Afisha.ru**.

> Посещение события часто начинается с простого «Пойдём?».
> Мы превращаем обычное приглашение в яркую персональную открытку,
> которой хочется поделиться с друзьями.

Пользователь выбирает событие, получателя и стиль общения — ИИ генерирует
текст и визуал открытки, готовой к отправке в мессенджеры. Каждая открытка
ведёт получателя обратно к событию на Афише, создавая вирусную петлю.

## Архитектура

Проект состоит из **двух независимых приложений**, связанных как настоящая
Афиша и встроенная в неё фича:

```
┌────────────────────────────────────┐        ┌─────────────────────────┐
│  afisha-mock (декорация Афиши)       │        │  generator (НАШ продукт) │
│                                      │ событие │                         │
│  • каталог событий                   │  по ID  │  • получает данные       │
│  • парсер afisha.ru ──> наполняет     │ ───────>│    по ID через API       │
│  • API: GET /api/event/[id]          │        │  • генерит открытку (ИИ)  │
│  • «добавить событие по ссылке»      │        │  • шеринг + лендинг       │
└────────────────────────────────────┘        └─────────────────────────┘
```

**Ключевая идея:** парсер живёт в `afisha-mock` и играет роль наполнителя
каталога (имитирует базу Афиши). Сам продукт — `generator` — данные **не
парсит**, а получает их по ID, как было бы при реальном внедрении в Афишу.
В продакшене «API мини-Афиши» просто заменяется внутренним API Афиши, и код
генератора не меняется.

## Структура репозитория

```
.
├── afisha-mock/     # декорация Афиши + слой данных (здесь парсер и API)
├── generator/       # наш продукт — генератор открыток
└── Info/            # материалы кейса
```

## Технологии

- **Next.js 16** (App Router) + **TypeScript**
- **Tailwind CSS**
- **PostgreSQL** (в Docker) + **Prisma ORM** — каталог событий мини-Афиши
- **cheerio** — парсинг страниц afisha.ru (OpenGraph + JSON-LD)
- ИИ-генерация текста и визуала — подключается на следующем этапе

## Запуск

Нужны **Node.js 20+** и **Docker** (для базы данных мини-Афиши).

### Быстрый старт (Makefile)

```bash
make install   # установить всё и подготовить БД (один раз)
make dev       # запустить оба сайта: Афиша :3000 + генератор :3001
```

`make help` — список всех команд. Ниже — те же шаги вручную.

### 1. Мини-Афиша (порт 3000)

```bash
cd afisha-mock
cp .env.example .env          # строка подключения к БД
docker compose up -d          # поднять Postgres (нужен Docker)
npm install
npx prisma migrate deploy     # создать таблицы
npx prisma generate           # сгенерировать Prisma-клиент
npx tsx scripts/seed.ts       # наполнить каталог из prisma/seed-data.json
npm run dev                   # http://localhost:3000
```

> `seed.ts` берёт события из готового файла `prisma/seed-data.json` — **без
> обращения к Афише**. Обновить каталог из Афиши (редко, одному человеку):
> `npx tsx scripts/refresh-catalog.ts`, затем `npx tsx scripts/export-catalog.ts`
> и закоммитить обновлённый `seed-data.json`.

### 2. Генератор открыток (порт 3001)

```bash
cd generator
cp .env.example .env
npm install
npm run dev                   # http://localhost:3001
```

Запускайте оба приложения одновременно: мини-Афиша отдаёт данные событий,
генератор их потребляет. Демо-сценарий: откройте http://localhost:3000, выберите
событие → «Позвать друга» → попадёте в генератор открытки.

### Проверка парсера

```bash
cd afisha-mock
npx tsx scripts/test-parser.ts "https://www.afisha.ru/movie/..."
```
